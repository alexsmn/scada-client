WHAT THIS IS FOR

  The Telecontrol SCADA Client ("the Program") is licensed under the GNU
  General Public License version 3, the text of which is in the file LICENSE
  beside this one.

  The Program draws schematic displays by loading a separate shared library at
  run time -- the Telecontrol SCADA schematic display runtime ("the Runtime"),
  distributed as `libdisplay_runtime.dylib`, `libdisplay_runtime.so` or
  `display_runtime.dll`. The Runtime is not free software and its source code
  is not published. The Program is specifically designed to load it, through
  the C interface described in `display/abi/display_abi.h`.

  Section 1 of the GPL defines the Corresponding Source of a work to include
  the source for shared libraries that the work is "specifically designed to
  require". Without the permission below, conveying the Program together with
  the Runtime -- or conveying a copy of the Program intended to be used with
  it -- would oblige the conveyor to provide the Runtime's source, which they
  cannot do. The permission below lifts exactly that obligation and nothing
  else.

  A. WHAT "TELECONTROL" HAS TO BE, AND WHAT IS STILL MISSING. Until
     2026-09-20 no file in this repository asserted copyright in the Program
     at all, so clause 1 named nobody. It now names Telecontrol, and the
     matching notice is in `COPYRIGHT` and `README.md`. Three things are still
     owed before this is safe to adopt:

       i.  SETTLED 2026-09-20. Clauses 1 and 4 named the trading name
           "Telecontrol", which is not a legal entity, and a section 7 grant
           has to identify who is granting it well enough to be binding. They
           now name the registered entity, and `COPYRIGHT`, `README.md`, the
           runtime's own licence and the About dialog all match it. The Latin
           form is primary because this permission is read by people who do
           not read Cyrillic; the registered Cyrillic form follows in
           parentheses so the entity is identifiable in the register it is
           actually in. Check the punctuation of the registered form against
           the incorporation documents before adopting -- the quotation marks
           around a Russian company name are part of the registered name.

       ii. The year range 2017-2026 is taken from this repository's first
           commit (2017-08-24, "Initial.") and today. If the work was first
           published before that commit, or under another entity, the range
           and possibly the holder are wrong.

      iii. NOTHING IS ASSERTED PER FILE. The notice is at the root of the work
           only; the 1094 source files carry none. That is a defensible way to
           license a work distributed whole, and it is not what the FSF
           recommends -- a file copied out of the tree on its own carries no
           notice and no licence. See `docs/adr/0013-display-c-abi.md`.

     NOTE WHAT MUST NOT BE DONE: do not fill in the `<year>` and
     `<name of author>` placeholders in `LICENSE`. They are part of the GPL's
     "How to Apply These Terms" appendix -- a template to copy OUT into your
     own files -- and the licence text says of itself, in its second
     paragraph, that copying it verbatim is permitted "but changing it is not
     allowed". An earlier draft of this note said to fill them in; that was
     wrong.

  B. THE THIRD-PARTY CODE IN THE PROGRAM DOES NOT BLOCK THIS. The only
     third-party copyrights in the client tree are permissive and allow
     sublicensing and relicensing: the Lucide/Feather icons
     (`res/icons/LICENSE`, ISC), `app/qt/DeployQt.cmake` (MIT, Nathan Osman),
     and a WebKit-derived helper in `aui/os_exchange_data.cpp` (BSD-2-clause,

  C. THE SAME QUESTION SITS ON THE CLIENT PACKAGE, NOT JUST THE DOWNLOAD.
     `app/qt/CMakeLists.txt` has an `install()` rule that copies the Runtime

     this permission just as the release asset does.

  D. THIS FILE MUST REACH RECIPIENTS. It is published automatically: the
     export maps the whole `client/` directory to the public repository root

     permission exists.

  E. MODEL AND DIRECTION. This is deliberately shaped like the GNU Classpath
     exception rather than the OpenSSL one. The OpenSSL exception's closing
     sentence requires Corresponding Source to include the source of the
     linked library, which works because OpenSSL is open and would defeat the
     whole purpose here. Read clause 2 carefully for that reason: it is the
     inverse of the sentence a reader may be expecting.
